# Security Policy

## Intended Use

This project is for authorized lab/research only. Use it only on systems you own or have explicit permission to test. Do not use it to access, monitor, exploit, or collect data from systems, accounts, or networks without authorization.

## Reporting a Concern

Please do not publish sensitive vulnerability details, credentials, tokens, logs, or personal data in a public issue. Contact the author directly:

- **Author:** Nguyen Xuan Hai
- **LinkedIn:** [linkedin.com/in/xuanhai0913](https://www.linkedin.com/in/xuanhai0913/)
- **Facebook:** [facebook.com/nguyenhai0913](https://www.facebook.com/nguyenhai0913)

For non-sensitive documentation or code-quality issues, open a GitHub issue in the relevant repository.

## Responsible Disclosure

When reporting a concern, include the affected file or component, a concise description, reproduction details that do not expose real targets or secrets, and any suggested mitigation.
